# 照相馆结构

- 用户任务：选择一项姿势和一个已有角色，合成一张可下载的角色姿势照片；图库含 288 组 / 1439 角度姿势图。
- 核心结构：桌面姿势参考 → 中央冲印照片 → 角色肖像；手机按选择姿势、选角、中央成片，底部固定拍摄入口。
- 核心主动作：生成一个选定姿势 + 角色的成片。
- 关键状态：空底片、服务未就绪、排队/生成/冲印、失败可重试、历史照片和全屏图库。
- 设备：侧栏宿主内桌面三栏；窄视口单栏与安全区内固定主操作；200% 缩放下中央区域保底宽度。
- 动效：页面/姿势切换、全屏弹窗开合按统一 300ms；生成状态只表现实际后台任务进度。
- 验收：核对真实工作流两张输入图像含义与顺序、桌面及 320px 手机视口、截图归属冻结、AVIF 图库完整性。
