# HD2D 生活链契约（M0）

2026-09-08：本文件冻结后续实现共同遵循的身份、时间、事务与兼容边界。实施与验收进度另记，不以契约声明代替功能完成。

## 世界与人物

- 一个本地存档只有一个稳定 `worldId`。地图重建递增 `worldEpoch`，不重新生成世界 ID，不以地图自增 ID 作为经济归属。
- 人物业务引用使用 `actorId`；旧 `me`、`npc:{id}`、`char:{id}` 仅用于渲染、SSE 与历史兼容。NPC 与其邀请后的角色绑定同一 actor；重复邀请不建第二个人物。
- 已关联角色入住时优先使用角色日程、立绘与聊天历史，原 NPC 不能同时出现第二个实体。退住仍保留 actor 履历；删除一侧身份不删除业务事实。
- 归档或合并的人物 ID 永不复用。后续钱包、库存、订单、服务和初始资金唯一键必须引用 actor，不能因为改名、重新入住或重复 seed 再发钱。
- 异步任务持有开始时的 world/epoch 与实体版本。提交前重新检查；内存场景重载还需要装载代次，避免旧演员回包作用到重新加载后的同名实体。

## 地点与场景

- POI 的业务标识为世界内稳定 `locationKey`；现有自增 `id` 保持兼容，同 key 编辑采用更新，不能删后重建。
- 地图 `PUT` 缺省 `locations` 表示保留原地点；显式数组表示更新地点集合；空数组表示显式删除。无效、重复、跨地图身份必须在写入前拒绝。
- 删除地点先处理引用和在途业务，不能留下悬空的家地址。未来商店/动作使用 locationKey；有在途任务的地点删除需要拒绝或原子补偿。
- 逻辑位置使用格坐标；渲染投影、贴片尺寸和美术元数据不改变 A*、到达与物品归属。画面适配继续遵循 `TownSceneAdapter` 与共享 projection。

## 时间、状态与规则

- 持久时间为 UTC 毫秒；作息窗口显式使用配置时区。冷却使用绝对时间差，跨午夜不重置，时钟回拨不产生额外收益。
- 请求先推进服务端位置再检查到达；`dueAt` 只代表最早执行时间，不能替代权威位置、库存、资格与预约验证。
- `activityText` 是本地活动说明；可选 `flavorText` 和气泡只是表达，不能反向成为劳动、交货、产物或支付事实。
- 规则是有限类型 AST，事实来自同次只读快照；不得执行任意代码、查询或自然语言条件。新增规则不能扩张动作执行器权限。
- 动作持有版本、原因、资源认领与世界 epoch；终态不可再次推进，取消/失败必须释放资源。无模型时本地规则仍可推进。

## 钱物、服务与事件（后续里程碑约束）

- 金额与物料数量使用有界整数。普通转账借贷总和为零，非系统账户不可透支；初始资金也通过唯一账本事务产生。
- 命令携带 `idempotencyKey`、实体 `expectedVersion`；同 key 同请求返回原收据，同 key 不同内容拒绝，不以覆盖旧结果实现重试。
- 扣款、钱物归属、业务终态、收据与领域事件必须在同一 SQLite 事务内提交。模型/网络调用在事务外；广播在提交后。
- 主题服务有明确 `created/active/settling/completed/cancelled/failed` 状态、硬回合上限、托管与退款策略；模型的 finish 是建议，本地事实决定可用 outcome。
- 领域事件不可修改，携带来源、因果、world/epoch、顺序 cursor。每个消费者的投递记录唯一，限次退避，过期认领可恢复；表达失败不回滚钱物事实。
- 关闭经济只禁止新交易，仍处理在途恢复和退款。重置地图先处理在途资源和旧 epoch，保留玩家背包与经济历史。不得在已有新交易后直接回退到不理解归属字段的旧程序。

## 验证与交付边界

迁移使用内存/临时 SQLite fixture；集成启动必须显式设置隔离 `DB_PATH`，不运行默认业务后端。UI 复用设计系统和统一组件，构建输出到 `output`，不能覆盖 `agent-core/public`。各阶段应记录实际测试命令、通过数、失败项和未覆盖项；安卓真机、真实存档手工验收与长跑经济平衡不能由桌面 fixture 推断完成。
