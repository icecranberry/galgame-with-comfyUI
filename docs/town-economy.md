# 小镇挣钱玩法

> 历史设计记录：本文描述的步骤式打工、订单和铭牌玩法已退出当前主链路，原测试与预览入口已清理。当前小镇玩法以 NPC 邀请 → 奇遇叙事推进为准；现行回归入口见 [测试维护说明](testing.md)。

小镇货币沿用「金币」。目标是空钱包也能开始做事，常回来能稳步攒钱，接单次数与真实结算共同约束产出。UI 以点击 NPC 打开的 `TownDialogueStage.vue` 为参考，使用工作牌、对话选择、任务步骤和结算回执。

## 接单机会

- 开张时有 3 次；按北京时间每日补 3 次，最多存 9 次，进行中的可退机会也占存储上限。
- 各店打工、玩家配送、可挣钱的奇遇托付共用。接受托付后去做其要求的当班，两者只扣一次。
- 取消未完成的任务退回机会；关联当班已经领过工资，就不能通过放弃托付退回机会。关联当班还在进行时，等它完成或取消再确定退回。
- 钱包、机会、手艺进度与已购铭牌跨重启和地图版本保留。旧地图请求不能继续操作。
- 消费不占接单机会。消费返还型奇遇显示净花费；有正收益或直接道具奖励的托付仍受机会限制。

## 可玩的收入来源

| 玩法 | 收益与要求 |
| --- | --- |
| 门店帮工 | 沿用各店保底工资；咖啡馆 24，酒馆 26，客栈 24，书斋 20。完成 3 次具体工作选择后收尾，每次选对增加 2 金币小费，最多 6；选错照付保底。 |
| 无本金跑腿 | 公告站捎信 24、传开工消息 26，居民找雨伞 18。按步骤到场，不用先买货。 |
| 手艺订单 | 完成 3 次裁缝铺帮工后解锁，4 次工作选择，保底 36、小费最多 6，与普通当班共用机会。 |
| 周末夜市 | 核对备料、酒馆当班、公告站交接，额外奖励 60，加当班工资 26、小费最多 6；关闭后冷却 7 天，地图重建不刷新。 |

新当班可以离开后继续，24 小时内回到店里完成即可；对话关闭本身不会取消。工资与小费由服务端规则结算，LLM 文案不决定金额和判分。一次服务回执只能推进一份托付。

## 持续供给与花钱目标

初始店铺资金只发一次。已接受、受机会约束的差事如缺少工资或一份原料，由外来订单垫付补足；取消时撤回未消耗的原料及垫款，完成才结算。付费消费缺料时可采购一份，完成后从商家收入中回收 6 金币采购款。所有钱物变化仍写原账本。

钱袋提供花信木牌（160）、海风铭牌（320）、星灯铭牌（800）。购买后永久拥有，可免费切换或收起；装备效果出现在地图镇名旁与公告站。购买款退出流通，服务消费继续给玩家提供日常花钱的选择。

示例：咖啡馆每天做 3 班、全部选对，收入 90；当天喝 2 杯 18 金币的咖啡，净积累 54。它是一个验证场景，其他门店、托付组合、积存机会和周任务会改变当日收益。基础数值需结合后续实际游玩数据继续调节。
