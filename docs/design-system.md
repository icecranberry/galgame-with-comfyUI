# 邻舍.EXE Design System

邻舍.EXE 采用 **Soft Warm UI**：温暖、柔和、轻盈、克制、内容优先。

Toast、世界观、信箱是当前设计语言的主要参考，新功能和新页面应从它们延伸，而不是创造新的视觉体系。

## 视觉

* 页面使用暖灰 / 米灰，内容使用暖白。
* 珊瑚色用于主操作、选中和强调，不大面积装饰。
* 使用柔和圆角和低存在感阴影，避免明显边框。
* 通过留白、字号、字重和浅色差建立层级，少用 Divider。
* 避免 Card 套 Card、厚重阴影、强渐变、玻璃拟态和 SaaS / 后台管理风格。

## 组件

* 主操作：珊瑚色实心；次要操作降低视觉权重。
* 不同重要性的按钮必须有明确层级。
* Toast 是轻量浮层的核心参考。
* Modal / Dialog 应视为 Toast 的扩展，而不是另一套设计。
* 优先复用已有组件、样式和交互模式。

## 设计原则

新功能设计时先明确内容、主要操作和信息层级，再决定组件和布局。

**目标：让新功能看起来像“邻舍的一部分”，而不是后来添加的独立页面。**
