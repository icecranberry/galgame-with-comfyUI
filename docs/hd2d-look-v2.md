# HD2D 视觉返工：以八方旅人参考图为目标

用户指出首轮只有渲染技术接入，画面缺少参考图中的建筑投影、受光层次和空间气氛。本轮把视觉基准改为：光照形成大块街面投影，屋顶与两侧立面有明暗差，近景遮挡失焦、人物清晰、远处逐渐雾化；默认站在街道中看世界，不自动缩小到整张菱形地图。

## 实际改动

- **光照重做**：定向日光明显强于冷色环境补光，侧向光位使投影横跨街面；日落影子更长，阴雨降低方向光反差。标准档 2048² 阴影，低配仍保留 1024² 阴影。
- **建筑投影改为体积**：按逻辑 footprint 生成墙身 + 山墙屋顶棱柱，仅参与阴影。主图不同时投第二份影子。根部增加接触暗部；树、灯、人物仍投透明轮廓影。
- **立面受光**：固定镜头下使用近似浮雕法线区分旧图的左右立面与屋顶，保留部分素材固有的绘制细节。灯具上部亮色玻璃使用自发光，配合受控高光扩散。
- **景深重做**：世界颜色缓冲同时写真实深度（包括 alpha 裁切），前后景按与焦点的距离失焦；两遍半分辨率九点 Gaussian，清晰焦段覆盖玩家与交互对象。关闭景深仍保留光影和色调。没有额外忽略贴片 alpha 的 override depth 通道。
- **画面合成**：线性 HDR、ACES 输出、冷暖分色、轻暗角与深度雾化。缺少浮点颜色缓冲支持时退到字节缓冲；UI、名字与对话文字保持清晰。
- **地面与构图**：草地更深地采样菱形内部以减少格线，降低草地饱和度、增加连续世界坐标的色差；道路边缘增加很低的真实路缘体积。地图外只延续不可交互的地景，不扩大行走范围。默认跟随玩家的街道取景（桌面 zoom=1.5，窄屏 1.15），人物显示高度从 64 调至 48 世界像素，原 PNG 不重采样；HD2D 平时隐藏姓名糖纸，仅悬停/选中显示。

`sceneLook.js` 统一照明、材质和建筑投影几何；`terrainEdges.js` 只派生路缘。`TownSceneAdapter` 显式保留 `grid`（逻辑锚点），与显示投影后的 `x/y` 分开；避免把屏幕像素用于体积/接触影的位置。更换素材类型或 footprint 时重建相应材质与投影资源。

## 验证

- 8 项渲染单测通过，覆盖坐标往返、锚点分离、体积包围盒、方向光反差、道路边缘、UV、边缘派生、透明拾取。
- 同场景开启/关闭方向阴影，读回实际 framebuffer：超过 2 万像素的平均 RGB 差值大于 35，最大差值超过 130，避免以“shadow 开关已启用”代替视觉验收。
- 街景 8 个建筑均只有一份投影来源；世界深度缓冲存在，GL error=0。
- 50×50、40 建筑、26 居民，低配仍有方向阴影；本机 Chrome 1100×650、DPR=1，60 帧 p50≈16.7ms / p95≈16.8ms。仅是该场景的帧间隔，不外推 Android。
- 20 次画质切换、20 次卸载/重挂、缺 WebGL2、context lost、编辑建筑与保存载荷测试通过；dispose 后 Three 的几何体/纹理统计均为 0。
- 前端隔离构建成功，207 modules，渲染 chunk 约 547 kB（gzip 140 kB）；原有混合导入和 bundle 警告仍在。

截图保存在 [`output/hd2d-look-v2`](../output/hd2d-look-v2/)。`day.png` 与第一轮 `output/hd2d-m1/day.png` 使用相同两栋建筑场景，便于比较真实渲染变化。`street-day.png`、`street-no-dof.png`、`street-sunset.png` 使用已有本机素材组成更密集的隔离街景，展示遮挡、树影与前景景深；该街景**不是写入真实存档的新布局**。`town-page.png` 是实际 TownView 的隔离页面截图。

复现命令沿用 M1 浏览器脚本，增加 `$env:HD2D_TEST_OUTPUT = '绝对路径/output/hd2d-look-v2'`；真实素材模式使用 `$env:TOWN_REAL_ASSETS = '1'`。本轮没有启动业务后端、调用模型或改动存档；构建仍写隔离 outDir。

## 仍然存在的美术边界

建筑可见外观仍来自旧等距 PNG；墙面/屋顶法线是近似，阴影棱柱也需要特殊建筑逐栋校准，不等于已经重建完整建筑模型。可用 `shadowMode: 'alpha_card'` 或 `none` 覆盖不适合通用体积的建筑。树木、石路和人物素材的画法仍有差异，部分道具还带旧图绘制的底座。

参考图里的桥洞、台阶高差、多层街道、分面屋檐和完整像素材质，需要继续推进实际可见建筑体积与美术重制。本轮显著重做光影与取景，但不声称已达到参考游戏的美术完成度。


## 后续调整：明快色调与小物件落地（v3）

- 提高日间环境补光与曝光，地面改为更浅的材质乘色；恢复草地饱和度，减轻根部压暗、冷色分级和暗角，保留方向投影与景深。
- 花箱、路灯、长椅等非建筑贴片按 alpha cutoff 扫描可见底边并缓存。以该底边落地，同时沿视线方向补偿世界坐标，保持屏幕位置不跳动；显式 anchor.v 仍优先，建筑体积投影维持原锚点。
- 道具接触阴影改为同一落地点，不再使用 footprint 中心，保留原有抗阴影杂点参数。
- 9 项单测通过；真实素材浏览器回归验证花箱（含翻转）、路灯、长椅可见底边世界高度为 0，地面脚点投影误差小于 1e-6 像素。建筑仍为 8 个独立体积投影，无重复阴影；画质切换、编辑保存、移动、生命周期和 WebGL 回退检查通过。
- 新截图与报告：`output/hd2d-look-v3/street-day.png`、`prop-feet.png`、`verification.json`。使用隔离街景与已有本机素材，未改动真实地图存档。


## 后续调整：投影贴合、行走与角色抗锯齿（v4）

v3 的可见脚点校准没有消除 shadow map 的 bias 间隙。v4 对非建筑 alpha_card 道具改用沿日光方向投到地面的透明轮廓几何，关闭同物件的 shadow-map 投射；仅采样素材 alpha，不把花叶颜色带入阴影。建筑仍使用原来的体积阴影。当前平面投影面向平地小镇，不会投射到其他建筑立面或未来的高差台阶。

Canvas 与 HD2D 共用 agentMotion：行走周期与原 Canvas 一致，最大跳高 2.2 个投影像素，待机轻浮动、睡眠停止；接触影始终贴地。TownView 单一 RAF 时间传给渲染适配层，无额外定时器。

世界合成目标启用硬件支持范围内的 4× MSAA，角色 alpha-to-coverage 平滑裁切轮廓，线性角色纹理增加 mipmaps，减少缩小时的闪烁；道具和地砖保持原像素过滤。后处理深度缓冲与透明拾取继续保留。

验证：10 项单测、前端隔离构建、完整真实素材浏览器回归通过。新增实际 mesh 行走高度与固定接触影检查；投影几何在花箱（含翻转）、路灯和长椅底边的位置误差小于 1e-5 世界单位；MSAA=4、alpha-to-coverage 和 mipmaps 生效。截图和报告位于 `output/hd2d-look-v4`。


## 可调俯视角度与人物尺寸

顶部使用统一 LinsheInput 提供 20°–60° 俯视角度，默认 30°，本地保存 `town.cameraPitch`。只在 HD2D 显示；兼容 Canvas 维持原投影。实际调整正交镜头仰角，固定方位角；拖拽、鼠标缩放、编辑格子与预览随投影同步，人物文字标签保持正常比例。

人物纹理宽高同时放大 1.5 倍：常规 48→72，HD 占位 32→48，Canvas 站立后备 52→78；透明拾取区域与头顶气泡同步调整。11 项单测及浏览器回归通过，包括 20°/45°/60° 地面射线往返、45° 控件与偏好保存；实际页面截图 `output/hd2d-camera/camera-45-page.png`。


## 遮挡排序修复与固定镜头

已按最新要求移除俯视角控件与偏好读取，镜头固定回 30°；保留人物 1.5 倍尺寸。此前“可调俯视角度”一节仅为历史记录。

人物和物件卡片按地面锚点深度稳定排序，同深度人物靠前，不让跳动高度参与排序。颜色绘制关闭卡片相互间的深度测试，以明确顺序消除贴片穿插闪烁；仍写深度供景深使用，阴影材质保持独立。透明拾取优先顺序同步画面层级。

建筑在画面中覆盖后方人物时降至 32% 不透明度，人物先画、建筑后画，因此人物仍在建筑后层；前方人物不触发淡化。遮挡检测采样建筑素材 alpha，减少透明留白误触发。

验证：12 项单测、隔离前端构建、完整浏览器回归通过；新增 12 个跳动时刻排序不变、前方建筑不透明/后方建筑淡化断言。对照图：`output/hd2d-occlusion/character-front.png` 与 `character-behind.png`；无 WebGL/页面错误。


## 遮挡点击、连续改道与 NPC 对话舞台

- 普通角色交互使用 agentsOnly 透明像素拾取，建筑后的角色仍可点击，保持视觉排序；地图编辑仍用原来的物件拾取规则。
- 玩家连续点击保留当前未走完的一段边及其开始时间，从该边终点重新寻路，避免 advancePlayer 提前跳到下一格。方向键共用该规则；快照使用路线原点而非 tick 后的格子位置。玩家移动事件增加单调 revision，前端忽略旧事件。此项涉及后端服务代码。
- NPC 立绘在左、玩家已有立绘在右，中间为 SVG 略不规则暖纸对话框；使用统一输入与按钮，保留历史、发送、回应状态、立绘放大，窄屏将对话框移到双立绘下方。无立绘时显示名字占位，不自动生成图片。
- 后端移动/寻路/地点测试 15 项通过，包括近百次连续改道的位置和速度保持；渲染测试 12 项通过。浏览器回归新增建筑后拾取、NPC 点击、模拟聊天发送、两侧真实素材立绘、桌面与 390px 窄屏检查。对话 API 均被测试桩拦截，未发送真实聊天消息。

## 手机世界横屏首轮

粗指针手机在竖向视口（宽度 ≤900px）进入世界时，将世界内容顺时针旋转 90°，按宿主可用区域交换宽高；真正横屏时取消额外旋转。只作用于世界路由，不锁定系统方向、不改变其他标签页。画布尺寸改用布局坐标 clientWidth/clientHeight，保证旋转后的射线拾取与绘制一致；顶部和 NPC 对话使用世界容器宽度选择横向布局。

Chrome 手机触摸模拟验证 390×844 下世界布局为 844×390、旋转后触摸 NPC 可打开对话、对话三列横排；切为 844×390 时恢复无旋转。完整浏览器回归及构建通过，截图/报告 `output/town-mobile-landscape`。此阶段未改造管理弹窗等独立浮层。
