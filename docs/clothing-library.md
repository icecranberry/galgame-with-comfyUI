# 角色衣服库

入口：人物详情卡 → 外观服装 → 默认 / 私服 / 居家 / 睡衣 →「衣服库 · 选 tag 搭配」。

从 `E:\Download\文生图创作\0-语料\服装` 的九份 Markdown 语料提取英文 tag、中文 label、中文描述与子类，合并重复 tag。库中共有 **992 个唯一词条**，其中 952 个可用于静态外观并显示在衣服库中，40 个动作或场景词条保留在原始整理数据中但不显示。衣服库仅显示文本，不导入图片或示例角色身份。

支持中英文搜索、常显分类页签、可搜索的子类筛选和跨分类多选，最多 32 个 tag。搜索优先显示 tag 或名称匹配，再显示含义中的匹配。睡衣场景隐藏鞋袜词条及无可用词条的分类；搜索、子类和数量统计仅基于当前场景可用的词条。「只看已选」清除当前筛选，集中查看已选项；之后仍可搜索或按分类缩小范围。

词条采用紧凑卡片，宽屏双列、手机单列，完整保留中文名称、英文 tag 和中文解释。筛选保持可见，列表连续滚动；首批显示 24 条，距离底部不足 240px 时自动追加最多 24 条，保留已显示词条、选中状态和滚动位置。没有手动翻页控件，加载完毕显示总数；切换搜索或筛选时回到顶部。窄屏通过「浏览衣服 / 搭配与提示词」切换，保留搜索、浏览位置和草稿状态；横屏矮窗口允许整体滚动。

生成会读取编辑中的默认外观，使用统一 `buildCharacterPersona` 入口保留角色身份与身体特征，按所选词条重新搭配服装。LLM 严格输出带 `appearance` 与 `conflict` 的 JSON；冲突、非法结果、非英文描述和不满足赤脚约束的睡衣都不会应用。后端在英文外观后追加精确 `Outfit tags: ...` 行，避免模型改写或遗漏原始 tag。

提示词默认以正文连续阅读，可切换「编辑」自行修改；「应用」只回填打开时的那套场景草稿，点击详情卡「保存」才持久化。重开衣服库会从该套外观恢复 tag。改选或修改补充要求使旧生成结果失效，关闭窗口取消前端请求，迟到结果不能覆盖角色或其他场景。

运行时使用仓库内资源，不依赖 E 盘：

- `agent-core/resources/clothing-library.json`：整理后的唯一词条与分类。
- `agent-core/src/services/clothingLibrary.js`：词条校验、提示词分层与结果解析。
- `web-ui/src/components/ClothingLibraryModal.vue`：衣服库界面。

更新语料后，从仓库根目录重新执行纯文本导入器（仅使用 Node.js 内置模块）：

```powershell
node scripts/import-clothing-library.mjs 'E:\Download\文生图创作\0-语料\服装'
```

导入不会读取或修改图片，也不会修改原始文档、表格或 PDF。生成后的 JSON 随源码维护。原回归测试（`agent-core/test/clothingLibrary.test.js`、`web-ui/test/clothingDraft.test.js`）已随 2026-11-06 测试精简移除，需要时从 git 历史取回。
