## 已成立的 B 链边界

真实双岗位工作证明完成有限生产 → 当前世界代次解锁固定波波头服务 → 明确付费与有限四阶段 → 原背包授卡一次 → 玩家手动使用 → 原外观与人格更新 → 旧小镇素材标记需要更新。

独立真实模块测试已覆盖该链。授卡不会直接换装，结算经历只写获得发型卡；使用后24小时效果和素材过期标记另有实际模块验证。旧心情修复贴继续保留原请求兼容和免费回访资格，波波头服务不增加该权益。详见 [B 服务](hd2d-m6-bob-cut-service.md) 和 [外观来源](hd2d-m6-appearance-signature.md)。

## 证据与限制

- [私聊上下文](hd2d-m6-chat-life-context.md)、[原回信](hd2d-m6-mailbox-life-context.md)、[原朋友圈](hd2d-m6-moments-life-context.md)、[原群聊](hd2d-m6-group-life-context.md)、[首次奇遇](hd2d-m6-event-life-context.md) 分别有实际源码隔离测试；fake 模型捕获发送消息，不能替代真实模型的表达质量验收。
- [信箱任务](hd2d-m6-mailbox-tasks.md)、[日程记录](hd2d-m6-schedule-overlays.md) 另有真实路由/组件浏览器证据；其模拟页面不作为资金或工作证明的来源。
- 动态记录不新增生成触发、模型次数、经济写入或原始聊天历史。调用前读取不等于模型内部并发槽等待、流生成中重建后的取消能力；各入口的具体晚响应边界以专题记录为准。
- A 链的天气缓存已保留完整预报时间，小镇按有效期同步读取；[咖啡馆固定经营/补货配送/饮品服务](hd2d-m6-cafe-chain.md)已接通后端，但天气需求选择、信箱咖啡馆任务卡、生活帖正式来源和咖啡馆 UI 尚未接通。C 展览与 D 熟客链也不能据此宣布完成。
