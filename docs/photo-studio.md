# 照相馆素材、授权与生成链路

姿势图库搜索框右侧可上传自定义参考图片（PNG/JPG/WEBP/GIF/AVIF，最多6MB），图库打开时也可直接粘贴剪贴板图片，复用同一上传识图流程；普通文字粘贴不受影响，关闭图库或离开页面后不处理图片粘贴，识别中不重复提交。`POST /api/photo-studio/describe-pose` 通过现有多模态 LLM 返回英文动作描述及主要人物数量，只使用破甲规则与固定任务规范，不注入世界观、强化或世界书。描述包含四肢、表情和简单场景／物品，不继承参考人物的外貌或衣服；主要人物支持一至两人，由识图自动判断，不提供单人／双人切换。成功参考图以内容哈希保存到 `/images/photo_studio/pose-ref-*`，编辑稿在 localStorage `photo-studio-custom-pose` 实时保存，切页、刷新和重启后恢复；本次选中状态沿用会话拍摄配置。选择普通图库或随机姿势不会删除自定义草稿，点击「补充描述」在同一行展开输入框，按钮变为「再次修改」；填写最多2000字的要求后点击或回车，重新读取已保存的原参考图并调用同一识图接口，要求仅附加在最终 user 中，成功更新并应用提示词，失败保留已有结果和草稿。补充要求随自定义姿势实时保存，新上传／粘贴成功后重置要求。预览、润色、拍摄共用原来的 `Pose:` 拼装段与角色编号替换；参考图只用于识图与预览，不传给生图工作流。所选拍摄背景继续独立应用。

`agent-core/assets/pose-gallery/manifest.json` 记录上游 commit、每张源图 SHA-256、像素尺寸、源大小及 AVIF 大小；`img/` 的原始图像和 `thumbs/` 缩略图均转换为 AVIF。`catalog.json` 保存全部 1439 个姿势索引。完整视觉识别稿保存在 `pose-prompts.json`；仅已完成逐图视觉校准的条目才进入照相馆，未识别或待复核条目不会显示或接受拍摄，避免选到没有动作描述的图片。维护/补拉图库：

```powershell
node agent-core/scripts/import-pose-gallery.mjs --source=<ai-pose-gallery-SKILL 本地工作副本>
```

照相馆沿用系统当前的 Anima 工作流，不将图库图片或头像上传作图像参考。姿势英文描述与 `buildCharacterImageAppearance` 取出的角色外观、所选背景及用户服装要求组成原始拼装稿。关闭 AI 润色时直接生图；开启时按基础规则 → 任务要求 → 独立 system 的共用生图规则 → short_prompt →【初步画面提示词】→ 唯一 user 的结构转换为单段英文提示词，不注入世界观、世界观强化或世界书，人物资料仅传 `short_prompt`，不传完整角色卡。服装、姿势 tag 逐字保留，用户额外服装优先，删除原服装的冲突内容。双人姿势优先使用用户选定的搭档，未指定时从其他角色随机补一人。尺寸默认 1152×2048，支持 1:1、3:2、2:3、4:3、3:4、16:9、9:16 与自定义。宽高滑条统一为512–2048、8px步长；固定比例联动缩放并按8px取整，短边最低512px（如9:16为512×912），自定义宽高独立调整，任务冻结保存尺寸。照相馆每次拍摄默认读取当前朋友圈画师串（config.comfyui.momentsArtist），显式留空时不注入画师串，仅配置缺失时回退通用画师串；保留独立生图的工作流与 LoRA 场景。最终照片保留 ComfyUI 返回的原始格式与字节，保存到 `/images/photo_studio/`；任务保存于 `photo_studio_jobs`，底层图像任务同步记入 `image_tasks`。

完成通知与「瞄一眼」一致：复用 `saveBase64Image` 保存原图，提交任务完成状态后，通过共享 `/api/stream` SSE 推送 `photo_studio_ready`（含任务状态、图片 URL 或失败原因）；进度使用 `photo_studio_progress`。展示链路不再同步编码 AVIF，启用的全局图片压缩仍按后台策略处理 PNG。前端订阅即时更新，重连时补取任务列表，每 15 秒查询仅作漏事件兜底，不再每 1.8 秒查询进度或每 7 秒重载全部资料。旧 HTTP 响应不能覆盖期间收到的 SSE 更新；离页取消订阅。

进度展示沿用日程「瞄一眼」的模拟与真实值混合规则：提交拍摄即从 0 开始，每隔 400–1600ms 随机推进 1–4 个百分点，模拟值最多 95%；进度条取模拟值向下取整与真实采样百分比的较大者，界面不显示百分比数字。真实值领先模拟值时暂停模拟推进，润色、排队、处理与保存阶段继续保留当前进度；图片保存成功后完成至 100%。新任务重置，提交期间转入正式任务不重启模拟；失败和离页停止计时，重进页面可接回运行任务。后端仍按当前采样轮次记录进度，不锁历史最大值，轮询时间估算通过 `estimated: true` 与真实采样区分。沿用原进度条、主题 token 与 300ms 缓动。

快门声只由实际按下快门的页面为本次提交的任务播放一次，在提交前登记任务 ID，成功／失败时消费。其他浏览器标签页及内嵌预览仍通过 SSE 或兜底查询同步照片，但不播放旁观任务的快门声；离页或刷新后不补播。重复完成通知、迟到响应均不重新登记音效。

成功的润色在服务内缓存最近 32 组；完整拍摄材料、实际入镜角色、LoRA、任务额外需求、规则及模型上下文相同时，再次按快门复用提示词并生成新照片。分辨率不参与润色缓存判断，只改变本次工作流的宽高；关闭润色的拍摄不写入润色缓存，首次开启且没有成功结果时必须先润色。润色失败不缓存；出图失败保留成功润色供重试。切页不清空缓存，重启后端会清空。

人物服装与姿势、背景共用 `photo-studio-selection` 会话存储：按主角／搭档位置保存衣柜场景、自选服装 tag、中文自定义描述及已翻译的英文词组，切页和刷新后恢复，主角与搭档互不覆盖；清除搭配即时更新存储。已删除的衣柜场景退回默认服装，不修改人物原衣柜。服装 tag 与自定义文字草稿按主角／搭档位置实时保存（包括空草稿），关闭、切页和刷新后恢复；「用于本次拍摄」负责翻译并应用草稿，文字修改后不复用旧翻译。选择衣柜服装或自动回退不会删除额外搭配及草稿；「清除本次搭配」才同时删除两者。

润色文本在后端直接交给生图，不经前端回传。若 tag 校验需要一次纠正，SSE 阶段显示 `polishing_retry`；提交／排队为 `queued`，ComfyUI 实际执行才显示 `generating`。ComfyUI WebSocket 按 `prompt_id` 隔离进度、错误和完成信号，`execution_success` 与 `executing node:null` 共用一次结算。前端保留本次挂载期间见过的终态，避免历史列表刷新移除条目后迟到消息把任务重新变成运行中。

原始描述样本是 `full_single_P001` 的正面、俯视、仰视、侧面与斜侧五个角度，以及以下三张逐图核对过的双人姿势：

- `pair60_P042_front`「盘腿相拥」：第一人坐地盘腿作为支撑，第二人面对面坐在其腿上并环抱肩腰。
- `pair60_P051_front`「耳边低语・手触脸颊」：第一人站前方抬手触碰后方伙伴脸颊，第二人靠近耳边并扶住其外侧髋部。
- `pair60_P054_front`「被横抱・背部后仰」：第一人为被横抱者，头肩后仰、双腿向另一侧伸出；第二人站立托住其上背与膝下。

双人描述除 `posePrompt` 外保存按主角／搭档顺序排列的 `characterRoles`。未检查的其他角度不自动套用正面描述。

原始拼装稿使用 `Pose:`、`Character N — Appearance:`、`Character N — Outfit:`、`Background:` 和可选 `Direction:` 标记绑定资料，预览展示该原稿。润色输出不保留这些标记，也不在润色后追加服装段，而是将每位角色的外观、最终服装、动作与位置融入自然语言。身份标签的作品名括号保留转义；原始服装和姿势 tag 的必要权重语法保留。服装组合拆成独立 tag 校验，允许调序、英文句首大小写和换行差异；姿势的显式下划线／权重 tag 与紧凑短语保留，长句及人物、镜头叙述按语义整理，不要求逐字复刻整句。真正遗漏 tag 时最多纠正一次，保持稳定 system 前缀和唯一末条 user；仍不合格或包含拼装标记时明确报错，失败不写缓存。异步任务失败通过 SSE 更新后在快门下方显示原因，避免仅在拍摄记录里才能看见。

原稿保存在 `image_tasks.prompt_original`，最终润色稿写入 `prompt_refined` 和拍摄任务，便于检查实际送入 Anima 的内容。角色分组与自然语言都不等于区域控制，不能保证每次生成完全复刻姿势。

新增描述须沿用来源体系/类别和姿势名称，但以图中骨盆、躯干、四肢支点与朝向、视角及透视为准，并在实际 Anima 出图后校验；不能只把名称翻译成几个泛化 tag。文本包裹不是空间约束，不能保证每次生成都精确复刻四肢接触点。


AI 润色旁的齿轮可反复展开／收起「任务额外需求」输入框（最多1000字），填写非空内容后变为主题橙色；内容随本次照相馆会话保存，开合保持300ms。按下快门立即收起输入框但保留草稿，需求仅在开启 AI 润色时发送到最后一条 user，并参与成功润色缓存判断。

服装配置绑定拍摄位置，切换角色、主搭档互换或随机搭档不切换搭配与草稿。旧配置按当前主角、搭档迁移一次；角色没有所选衣柜场景时临时回退默认，保留位置偏好。随机搭档同样接收搭档位置的 tag、自定义英文与可用衣柜场景，预览和拍摄共用此逻辑。
