邻舍桥接 · 人格管理

管理注入到 MaiBot 主聊天流的人格信息（base_prompt / 风格 / 记忆）与全部插件参数。

返回 MaiBot WebUI ↗

① 连接设置

WebUI 地址固定为本机 8001 端口，无需配置；Token 只保存在邻舍本地数据库，用于代你调用 MaiBot WebUI 接口修改插件配置与人格数据。

② 插件配置

人格注入与行为 / 表达风格提炼为始终开启：每次回复都会把 system 人格整条替换为所选角色的人格，并由 LLM 依据人格生成行为风格与表达风格一并注入请求，覆盖麦麦设置里的「行为风格」与「表达风格」。

每 40 句真实聊天内容整理一份摘要，注入 MaiBot 主聊天流历史，并同步回邻舍；关闭后不再整理，并删除已保存的记忆摘要。

配图由 MaiBot Planner 调用邻舍生图工具触发，异步生成后自动发送，不再按回复自动判断配图。

⚠ 人格覆盖提示

启用桥接后，所选角色的 人格卡片 将整条临时覆盖 MaiBot 当前 system 人格（覆盖MaiBot设置里的「人格设定」）；提炼的行为风格 / 表达风格也会作为请求指令注入，覆盖麦麦设置里的「行为风格」与「表达风格」。不改变MaiBot原有人格，仅做临时替换

以下三项数据保存在插件本地，不写入邻舍数据库，按角色独立；修改后点「保存到插件本地」立即生效，点「重新提炼并保存」会依据当前 base_prompt 重新生成行为/表达风格并保存；切换角色时若该角色还没有行为/表达风格，会自动提炼并保存。
