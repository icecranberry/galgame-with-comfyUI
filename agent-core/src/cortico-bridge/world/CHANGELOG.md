# Changelog

## Unreleased

- 新增 `linshe_draw` 泛用画图工具：走图片实验室「自由画面描述」链路，人物、物品、场景皆可画（描述里提到的角色自动带上其外观）；环境提示词改为画任何东西优先用它。
- 下线 `linshe_events` / `linshe_event` 奇遇查询工具（奇遇玩法回到邻舍本体内推进，不再暴露给 Cortico）。
- 环境提示词去掉「心跳自醒」措辞（自醒功能已从 bot 包移除，模型只在外部事件唤醒时看生活内容）。
- `linshe_schedule` 默认只返回当前时间前后一小时内的日程与当前活动（回执带 `scope` 与当前 `time`）；要讲一整天安排时传 `full=true` 获取完整日程。
